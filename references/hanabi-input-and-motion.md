# Hanabi 输入与动画研究笔记

来源：`hanabi-catalog.json` 中每个样式的公开编辑地址。网站输入格式是使用 Hanabi 编辑器时的约定；本 Skill 的自绘场景可使用归一化 JSON，不强迫用户把现有 Excel 改为 Hanabi 的 A/B/C 列布局。

## 已核实的输入区别

- 基础柱/条/饼/环常为类别和值两列。分组/堆叠常为首列类别、后续多个数值系列。百分比堆叠只适用于同分母组成。
- 动态双轴折线图默认 A 为横轴、B 为左轴、C 为右轴；基础折线柱状图默认 A 为类别、B 为右轴折线、C 为左轴柱形。不能交换而不更新图例与轴标题。
- 分组/堆叠柱线图的文本指引沿用了三列说明，但控件提供柱形/折线范围选择，缩略图也显示多柱系列。因此必须按实际系列角色和范围配置，不把“三列”硬写成所有柱线图的通用限制。
- 动态条形/动态对比条形默认前两列是颜色组、对象，后续列标题是时间，内部数值随时间变化。动态排名图本身可能只有两列；名称中带“动态”不保证有时间维度。
- 动态气泡默认六列，包含对象、颜色组、时间、X、Y、大小，说明明确把大小映射为面积。静态气泡的文字说明提到半径，且声称五列但未在正文解释第五列；配置控件实际包含 X/Y/名称/大小/颜色。自绘时把数量型大小映射到面积，显式半径字段则按半径处理，不能悄悄混用。
- 基础散点需要 X/Y，可附对象名；回归需要 X/Y。多维平行坐标需要对象/组和多个数值轴。雷达需要指标名和系列值，必须确保各轴可比较。
- 水平/垂直/径向树状图以若干层级名称列及末列叶值组织数据。多级饼/环、旭日等使用层级路径和末列数值，不能添加不存在的父节点。
- 网站瀑布图输入各阶段的实际值，再计算相邻差值。这不同于直接输入增减贡献的瀑布图实现。scene.json 中明确 `waterfall_input: level|delta`，先核对期初、期末和贡献。
- 箱型图输入类别和组内重复样本值。直方图读取样本分布并按箱数/箱宽计算，不把输入行号当分箱。
- 桑基/弦是来源、目的、权重三列；关系力导向另可含边描述；地图流向增加时间和地理位置角色。不能根据节点名字擅自解释关系性质。
- 甘特图是任务、开始、结束；区间条/柱是类别和两个数值端点；事件时间轴是日期、标题、事件、左右位置等文本结构，不是数值折线。
- 全国/分省地图先区分地区层级，名称须可匹配。动态版本可以按时间宽表；静态地图的部分指引复用了动态版本文字，实际单期地图不要虚构时间字段。
- 子弹图说明明确目标值、实际值和多个区间带，但对 D 列没有完整说明。实际制作以有定义的字段命名，不强行塞一列未知内容。

## 官网不足与核实状态

以下五项的“数据使用指引”为空：笛卡尔热力图、带标签折线图、动态时间轴（新）、人口金字塔、堆叠玉珏图。已检查缩略图与详细配置：

- 热力图可确定为二维分类/时段的强度矩阵，示例是各城市温度变化；私有列布局未确认。
- 带标签折线图可确定是折线节点加文本，控件提供节点显示和线宽；标签列的私有规则未确认。
- 新时间轴控件可映射时间段、内容标题、时间内容、偏移位置；不把旧时间轴的四/五列规范直接套用。
- 人口金字塔可确定为按年龄层两侧比较；原数据列布局未确认。
- 堆叠玉珏图可确定为同心弧段堆叠；原数据列布局未确认。

这些图形仍可按照清楚定义的归一化字段自绘，但不能声称已经验证了它们的 Hanabi 导入格式。现场使用 Hanabi 时应再看映射控件或用户给出的真实表格。

## 可借鉴的动画和设置

饼/环：整体顺时针、逐项顺时针、放大、沿路径、移入、淡入等。Vox 版本优先采用纸片展开或扇形逐项显现，保持最终角度准确，不把入场动画看成数据随时间变化。

柱/条：整体/逐项渐入、扩展、位移，配合标签和排序。时间竞赛图有变化速度、时间标注、对象数量、颜色组、0 值显示等；必须保留对象身份和真实时间。

折线：渐入、路径展开、节点显示、线宽、标签、平滑开关。Vox 版本保持纸页稳定，随后画线并贴注释；只有数据与插值允许时才平滑。

玫瑰：动态页可见弹跳、渐变、淡出及内半径设置。外观再吸引人也先核对它编码的是角度、面积、半径还是层级，不自动替代普通饼图。

时间轴：整体从上/下进入与轴线淡出/渐变，文字事件逐个出现。网络、桑基等采用节点先建立、连接后展开；不要让随机布局运动被误解为数据变化。

这些是网站可见配置的研究，不是对每个组合的性能/导出能力承诺。配色、字体、图例、标签、位置、时长和数据格式与图形类型分开。Vox 的大字、撕纸、胶带、纸纹与重点标记在精确图形之外统一应用，不能照搬 Hanabi 标志、水印、示例内容或宣称官方出品。
