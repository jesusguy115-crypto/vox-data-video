# 整张表只制作一张图表

用户要求的是全部数据进入同一张图表，不是只要求一个视频文件。左右两张图、上下两张图、先播放指标A再播放独立指标B，都不符合要求。

- 同一组球队/球员的数量与百分比：一组柱形叠加一组折线，共用类别轴，左右轴分别写明指标与单位。不能用次数轴读百分比。类别之间的连线只用于系列比较，不虚构时间趋势。
- 两个连续数值：同一张散点图，一点对应一个对象；姓名标签与横纵轴保留全部关系。未明确要求不能自动计算差值并增加结论。
- 完整组成：同一张饼图，扇区显示百分比，右侧只放名称和色块。
- 多对象随时间：同一张多系列折线或动态圆堆，保留对象身份与时期。
- 更多指标或不支持的数据结构：设计一个能容纳全部指标的单图，例如分组、堆叠、热图或带额外视觉编码的散点图。未经授权不能删除字段，也不能为了套现有模板拆成多张图。不要把没有合理共同语义的数据硬叠在一根轴上。

发布前核对输入有效列、对象行与最终图中的编码对应。存在数据缺失、标签重叠或模板容量不足时应处理具体问题；不能以提速为由省略数据。现成模板支持的任务直接生成，避免重新研究风格。
