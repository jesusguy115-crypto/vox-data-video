# 数据理解与选图


主题与强调效果遵守 theme-and-caption.md：目录中的重点圈线、标题、数字卡等是有用户授权时的可选动效；无主题只展开图表。选图不授权推测叙事意图。

建立数据字典，记录对象、时间、指标定义、单位、样本/时期、来源坐标和显示精度。分清单场、赛季、总量、场均、每回合与比例。体育指标名称相近时不能替代，例如投篮命中率和有效命中率。

先判断数据的关系和表达目的，再考虑图形。类别 + 占比、类别互斥、合计约 100% 时，首先识别为整体组成，不要因为可以排序就默认条形图。少量组成用饼图/环形图；强调精确比较细小差异时再优先条形图。同一份数据可能适合不同图形，说明选择表达的是组成、排名、趋势还是关联。

Excel 格式是线索，不是定义。百分比通常存为 0–1，但没有百分比格式的 0.45 也可能是分/回合；不能仅因值小于 1 就乘 100。保留空值与 0 的区别。

提取器不计算公式。公式缓存缺失、错误值、外部引用或核对不一致时，用支持的引擎对副本重算，或请用户在 Excel 保存最新计算结果。缓存存在不证明最新。不得擅改来源文件。

归一化数据保留 source_cell、unit、missing 和必要的 derived_from。视频点位估算单独标记，不以多位小数冒充精确数据。

| 需要回答的问题 | 优先考虑 | 注意 |
|---|---|---|
| 哪个对象更多 | 条形/柱形 | 长中文标签用横条；柱轴从零开始 |
| 随时间如何变化 | 折线 | 用实际时间间距；缺失不自动连线 |
| 两个指标的关联 | 散点 | 每点一个对象；关联不是因果 |
| 前后变化 | 哑铃/坡度 | 写清两个时点；避免多线交叉 |
| 一个整体由少量类别组成 | 饼图/环形图 | 约 2–6 类、互斥、非负、完整整体；直接标名称与占比 |
| 多个整体的组成对比 | 堆叠/100% 堆叠 | 分母一致；负数不是份额 |
| 多对象×同量纲指标 | 热力图/小多图 | 清楚标色阶；不硬套雷达图 |
| 同对象上叠加两指标 | 柱线组合 | 用户指定则保留；标明左右轴 |

饼图角度按数值 / 总和计算。四舍五入导致 99.99% 或 100.01% 时，闭合图形但保留原标签，注明尾差，不擅改某类数字。类别不互斥、有负值或只给部分总体时，不能强行闭合。类别多或差异小且重点是比较时用条形图。

不要为了制造相关性调整双轴尺度。柱轴从零起，两系列类别位置一致；跨柱的线条加细描边。不同单位不能视作同一尺度。时间顺序不可为排名打乱。

用户授权的叙事只陈述数据支持的范围，例如“这七人中 A 的每回合得分最高”，不写“A 是联盟最佳”。大量对象可分组或分段，披露筛选，不静默丢掉数据。动画先建立尺度和对象，再展示数据，仅在用户明确要求时强调重点，最后稳定停留。
